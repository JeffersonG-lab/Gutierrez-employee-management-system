# 5-8 Minute Video Tutorial Script

## 1. Introduction (30-45 seconds)
"Hello, this is my Employee Management System CRUD application. This project uses PHP, MySQL, XAMPP, Visual Studio Code, and GitHub."

## 2. GitHub Repository (45 seconds)
Show the public repository and explain the repository name. Show that the `sample-crud` branch exists.

## 3. Development Tools (30-45 seconds)
Show Visual Studio Code, XAMPP, and the running Apache and MySQL services. Mention phpMyAdmin or MySQL Workbench.

## 4. Database and Table (45-60 seconds)
Open phpMyAdmin/MySQL Workbench and show the `employee_management` database and `employees` table. Briefly explain the columns: employee ID, name, email, phone, department, position, salary, and date hired.

## 5. Source Code (1-2 minutes)
Open the five required CRUD files:
- `db.php`
- `index.php`
- `create.php`
- `edit.php`
- `delete.php`

Explain that `index.php` displays records, `create.php` inserts records, `edit.php` updates records, and `delete.php` removes records.

## 6. Demonstrate CRUD in Browser (2 minutes)
Open the application. Demonstrate:
1. **Create** - add a new employee.
2. **Read** - show the employee in the list.
3. **Update** - edit the employee's department or position.
4. **Delete** - delete the test employee and confirm it disappears.

## 7. Pull Request (30-45 seconds)
Return to GitHub and show the `sample-crud` branch and the pull request from `sample-crud` to `main`. Explain that the pull request has not been merged unless the teacher instructed you to merge it.

## 8. Closing (15 seconds)
"That concludes my Employee Management System CRUD demonstration. Thank you."
